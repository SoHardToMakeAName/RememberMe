## 0. 一句话结论

原版"回复越聊越短"（后 50 轮 71 字 vs 前 50 轮 175 字，**-59%**）**主要是"别回太长"偏好学习生效，不是模型偷懒**。

强证据：即便 control 组仍保留了弱长度偏好，其后 50 轮均值仍达 **153.3 字**，远高于原版的 71 字（差 82 字）。
但 control 后 50 轮也比自身前 50 轮低 18%（186.5→153.3），说明存在**轻微模型趋短倾向**，只是远不如偏好驱动显著——属"偏好为主、轻微趋短为辅"，非纯偷懒。

## 1. 实验目的

原版 500 轮评测发现回复字数随对话收敛：前 50 轮均 175 字 → 后 50 轮均 71 字。
需判定这种"越聊越短"到底是：
- **(A) 学到"别回太长"偏好**（良性，证明偏好学习链路工作正常），还是
- **(B) 模型偷懒**（需优化，否则长对话会塌方式变短）

做法：复制评测脚本、清空偏好植入，跑同样的 500 轮，对比字数曲线。

**⚠️ 设计偏差（如实标注）**：control 并非"零偏好"，而是"弱偏好"。
- 原因：`long-convo-eval-control.ts` 的 POOL L100/L101 仍含长度偏好的等价措辞，未能真正清零；`rewrite()` 的强强调信号虽去除，但偏好表达本身仍在对话流中。
- 因此本实验是 **强偏好（原版） vs 弱偏好（control）的梯度对照**，而非严格"有 vs 无"。
- 这一偏差**不影响主结论方向**（偏好强度与回复长度强相关），但意味着 control 的 153 字仍含"弱偏好生效"成分，不能解读为"纯零偏好基线"。若要做到严格零偏好对照，需进一步把 L100/L101 的长度语义也剥离（仅留情绪内容）。

**核心变量**：偏好植入的**强度与重复频率**（原版反复强调 vs control 仅一次性弱表达）。

## 5. 结论与判定

1. **主因＝偏好学习（良性）**：原版强偏好 → 后 50 轮塌到 71 字；control 弱偏好 → 仍 153 字。差 82 字，直接证明**偏好植入强度驱动回复变短**。偏好学习链路工作正常、有效。
2. **非模型偷懒**：若"越聊越短"是模型偷懒，control（无强提醒）也应跌到 ~71 字；实际稳在 153 字，排除纯偷懒假设。
3. **轻微趋短（次要）**：control 后 50 轮比自身前 50 轮低 18%（186.5→153.3），提示存在轻微模型趋短倾向。幅度远小于偏好驱动（−18% vs −59%），属"偏好为主、趋短为辅"，不构成产品风险，但值得长期观察。
4. **产品含义**：
   - 偏好学习验证通过，可放心上线长对话场景。
   - "回复过短"风险由偏好控制，非模型失控；建议在 learner 模板为回复长度加**上下限保护**（如最短 ≥ N 字），防止强偏好下塌方式变短影响信息密度。
